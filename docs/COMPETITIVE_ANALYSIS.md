# Competitive analysis

Public research on 7 October 2026 found active entries around trading desks, cross-protocol routing,
market-hours arbitrage, bad-quote refusal, AI stock analysis, portfolio agents and MCP wrappers.

## COMMON_IDEAS

- AI chooses a tokenized stock.
- Portfolio dashboard, basket, DCA or rebalance.
- Market-hours or cross-protocol spread scanner.
- Natural-language trade and wallet execution.
- Generic MCP wrapper around sponsor APIs.

## CROWDED_IDEAS

- Pure market-hours arbitrage.
- Cross-wrapper “best venue” tables.
- Autonomous trading agents.
- Dashboards that show a spread without proving executability.
- Chat interfaces with swap buttons.

## UNDEREXPLOITED_IDEAS

- A deterministic evidence sufficiency gate before agent execution.
- Replayable decision receipts with explicit unknowns and provenance quality.
- Separating headline spread from executable spread after slippage, cost and stale-reference risk.
- Refusal as the primary user outcome, not an edge case.
- Honest handling of the API's derived reference price.

## JUDGE_EXPECTATIONS

A working BSC tokenized-stock product, deep multi-module integration, resilient error handling, a fast UX,
an original use of the APIs and a specific human-written DX report. Agent special-prize judges need a genuine
execution-layer or Studio runtime integration, not a logo.

## BEST_DIFFERENTIATION_ANGLE

**Executable Truth Receipt:** one deterministic, evidence-linked artifact showing whether an apparently
attractive tokenized-stock action survives market state, source integrity, freshness, liquidity, slippage,
cost, wallet readiness and simulation. AI explains; deterministic policy decides.

Representative public signals reviewed: the official hackathon ideas, PARALLAX, RWA Stock Arbitrage Suite,
YoStocks, EquityMux, and BNB Chain's stock analyst Agent Studio demo. These are competitive signals, not copied code.
