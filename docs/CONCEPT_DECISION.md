## Choice

Build **Pulse Market Hours Agent** as an **Execution Safety Agent**, with the **Executable Truth Receipt** as
its differentiating product artifact. This preserves the memorable market-hours story while avoiding a crowded
arbitrage-scanner identity.

Primary target: main track. Secondary target: Agentic Wallet/Wallet Skills. BNB Agent Studio is a stretch target
only after the core live evidence and simulation path works.
